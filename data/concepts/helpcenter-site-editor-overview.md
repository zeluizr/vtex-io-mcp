Site Editor is a graphical interface for managing your storefront content. It allows you to create, edit, publish and schedule changes in your storefront components and behavior.

In your VTEX Admin, access **Storefront > Site Editor** to see the main tools available.

| **Tool** | **Description** |
|----------|----------------|
| Binding locale | Select the binding locale for content changes (e.g., English en-GB, Portuguese pt-BR, Spanish es-AR). |
| URL | Navigate between pages on your store. |
| Select a block | Select the block to create or modify content. |
| View mode | Check different view modes (mobile, tablet, desktop). |
| Preview | See a preview of storefront content in Site Editor. |
| Blocks | Add and edit blocks (Banner, Menu, Footer, etc.) to build and customize your storefront. |

## Key concepts

- Site Editor reflects the **Store Theme app** natively, enabling you to overwrite predefined block configurations.
- Site Editor does **not** allow adding new blocks to a template — only overwriting existing block configurations from the Store Theme app.
- Content created in Site Editor always prevails over what was defined in the Store Theme.
