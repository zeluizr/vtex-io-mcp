The version of a block is a copy of its content at a given time. For example, a Carousel can have predefined versions for future marketing campaigns (e.g., Black Friday, Valentine's Day) with specific banners.

With the **Versions** feature, you can create, schedule, and try different contents for a given block without compromising the published version of your store. Every block in the Site Editor can have multiple versions.

## Creating a new content version

1. In the VTEX Admin, access **Storefront > Site Editor**.
2. Click on the desired block (e.g., Slider-Layout), select **VERSIONS** and click **NEW VERSION**.
3. In the **Untitled content** field, enter a name (e.g., `Black Friday Campaign`).
4. Set up the block according to your preference and click `SAVE`.

The new version is saved but **not yet publicly available**. To publish it, activate it.

## Activating versions

1. Access **Storefront > Site Editor**.
2. Click on the desired block, select **VERSIONS**.
3. Choose the content you want to activate and click `More options` > **Activate**.

> You can only have one content active at a time. Activating one content deactivates the others.

> When accessing *Apply to*, the option *this URL* always appears above *this template*. If a block has two versions with different application options, the template version can only be reactivated after deleting the URL version.

## Scheduling content updates

After creating a new content version, you can schedule its publication using the **Visibility** feature. See [Scheduling content updates](https://help.vtex.com/en/tutorial/scheduling-content-updates).

## Deleting versions

1. Access **Storefront > Site Editor**.
2. Click on the desired block and select **VERSIONS**.
3. Choose the content you want to delete and click `More options` > **Delete**.
4. Click `DELETE` to permanently remove the version.

## Use cases

- **A/B testing**: Create two versions with different content, alternate between them to test which performs better.
- **Seasonal campaigns**: Create versions for Black Friday, Christmas, Valentine's Day, etc., and schedule their activation dates.
- **Rollback**: Keep the previous content version to quickly revert if the new version causes issues.
