Descriptions use a single sentence to clarify or explain complex information or tasks to the user. This pattern is frequently found in form fields and help-related components.

## General rules

Include a description only when additional information is actually necessary.

Keep it as short as possible while still being descriptive enough.

| Do | Don't |
| :---- | :---- |
| Volume of sessions in the intermediate stages of the purchase flow | This chart allows you to track the volume of sessions in the intermediate stages of the purchase flow and view opportunities for optimizing the conversion rate |

Use sentence case, but capitalize proper nouns.

Avoid punctuation such as commas, and don't use periods or question marks.

Don't include redundant words.

| Do | Don't |
| :---- | :---- |
| Label: Frequency — Description: Schedule for updates | Label: Frequency — Description: Frequency for updates |

Don't use a marketing tone of voice or explain benefits.

| Do | Don't |
| :---- | :---- |
| Volume of sessions in the intermediate stages of the purchase flow | Track the volume of sessions in the intermediate stages of the purchase flow to optimize your conversion rate |

## Specific rules

**When explaining a label**, write as if completing the sentence "This is the…". Start with a noun followed by additional information.

| Do | Don't |
| :---- | :---- |
| Label: Seller ID — Description: Seller identifier in the marketplace | Label: Seller ID — Description: This is the seller identifier in the marketplace |
| Label: Publish date — Description: Day in which the changes made will appear in the store | Label: Publish date — Description: When should the changes appear in the store? |

**When explaining how information will be used**, write as if completing the sentence "When you enter a value in this field, it…" and start with a verb in the simple present tense.

| Do | Don't |
| :---- | :---- |
| Label: Seller ID — Description: Appears to customers in the store | Label: Seller ID — Description: When you fill a value in this field, it appears to customers in the store |

**When explaining both the label and how its value will be used**, combine the two approaches above.

| Do |
| :---- |
| Label: Seller ID — Description: Seller identifier in the marketplace that appears to customers in the store |
| Label: Publish date — Description: Day in which the changes made will be published considering the time zone where the store is located |
