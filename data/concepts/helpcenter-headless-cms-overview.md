The Headless CMS is a content management system designed by VTEX to empower businesses with the flexibility to create and deliver content across various channels, such as websites and mobile apps.

The term *Headless* refers to the separation between the frontend (interface that displays content to the user) and the backend (system responsible for managing and storing content). This approach allows content management to occur independently of the user interface, providing flexibility and scalability. For example, a merchant can update a product page through Headless CMS without affecting the user experience on the website.

To access the Headless CMS, log in to the VTEX Admin and navigate to **Storefront > Headless CMS**.

> Required resources for Headless CMS management: *See CMS menu on the top-bar*, *Settings*, and *CMS GraphQL API* — associated with your user role.

## Managing Projects

[Projects](https://help.vtex.com/en/tutorial/managing-projects) is a feature in Headless CMS that allows you to create and manage multiple frontend projects (mobile apps, websites, email marketing) from a single control panel.

## Managing pages

Within each project, you can manage all URL routes and page templates for your store's website, including the home page, product page (PDP), and others. See [Managing Pages in the Headless CMS](https://help.vtex.com/en/tutorial/managing-pages).

## Managing Singleton content types

Singleton is a content type that simplifies content management by creating and managing a single page, guaranteeing the existence of only one version of this content type in the Headless CMS. See [Managing Singleton content types](https://help.vtex.com/en/tutorial/managing-singleton-content-types).

## Key differences from Site Editor

- Headless CMS is designed for **FastStore** (headless storefronts), while Site Editor is for **Store Framework** storefronts.
- Headless CMS separates frontend and backend, allowing content reuse across channels.
- Projects in Headless CMS can manage multiple frontend experiences from one panel.
