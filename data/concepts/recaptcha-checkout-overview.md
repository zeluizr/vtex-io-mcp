# reCAPTCHA in VTEX Checkout

reCAPTCHA is a tool used to determine if a given action is performed by a real user or malicious automation — particularly helpful in preventing ecommerce fraud.

VTEX is integrated with **reCAPTCHA Enterprise**, which offers two validation approaches:

| Approach | Equivalent | Recommended for |
|---|---|---|
| **Checkbox** | reCAPTCHA v2 | `vtexCriteria` validation mode |
| **Score-based** | reCAPTCHA v3 | `always` validation mode |

---

## Configuration

### Step 1 — Get current orderForm configuration

```
GET /api/checkout/pvt/configuration/orderForm
```

### Step 2 — Update recaptchaValidation

```
POST /api/checkout/pvt/configuration/orderForm
```

Set `recaptchaValidation` to one of:

| Value | Description |
|---|---|
| `"never"` | No purchases are validated with reCAPTCHA |
| `"always"` | All purchases are validated — recommended for **score-based (v3)** |
| `"vtexCriteria"` | Only some purchases validated; VTEX algorithm determines trustworthy sessions — recommended for **checkbox (v2)** |

> This configuration is valid for the **entire account**. It is not possible to activate reCAPTCHA for a limited number of bindings.

### Step 3 — Confirm activation

```
GET /api/checkout/pvt/configuration/orderForm
```

---

## Important Warnings

> ⚠️ Any integrations that deal with placing orders must be able to handle reCAPTCHA validation. If reCAPTCHA is required for a given order, it cannot be placed without validation. Native VTEX UI already handles this.

> ⚠️ In headless checkout or API-based order creation tests, reCAPTCHA in active mode can block order completion — the reCAPTCHA validation key can only be generated by displaying the reCAPTCHA widget, not via API alone.

## reCAPTCHA Score

Score-based reCAPTCHA returns a score for user interaction:

| Score | Meaning |
|---|---|
| `1.0` | Very likely a legitimate user |
| `0.9` | High confidence |
| `0.7` | VTEX default threshold |
| `0.3` | Suspicious |
| `0.1` | Very likely a bot |

Possible returned values: `0.1`, `0.3`, `0.7`, `0.9`

Interactions below the minimum score **cannot place orders**.

### Score Priority

```
reCAPTCHA key score > Account score > VTEX default score (0.7)
```

### Setting Account Minimum Score

1. `GET /api/checkout/pvt/configuration/orderForm`
2. `POST /api/checkout/pvt/configuration/orderForm` — add or modify `recaptchaMinScore` (decimal number)
