Tables and lists present structured content. Use lists to present a series of single items or steps. Use tables to organize data with multiple attributes.

## General rules

When a list or table item contains a colon, the first word after it must be capitalized.

| Do | Don't |
| ------ |-------- |
| **Authorized reservation:** After the order is placed. | **Authorized reservation:** after the order is placed. |

Make sure the list or table structure is consistent. Start each item with the same verb or noun form.

When a list or a word in the table is not a complete sentence, don't use punctuation.

## Lists

There are two types of lists:

- **Ordered:** Presented in a specific sequence, typically numbered. Use for sequential steps (e.g., installation instructions).
- **Unordered:** Presented without a specific sequence, typically bulleted. Use for groups of items without a specific order (e.g., required tools).

### Ordered list

Use a **numbered list** for sequential steps.

Write an introduction to the list providing context for the user. Use a colon at the end of the sentence if the list follows immediately after.

| Do | Don't |
| ------ | -------- |
| Follow the steps below to add a new collection: 1. In the Admin, click **Catalog**. 2. Click **Collections**. | Add a new collection: 1. In the Admin, click **Catalog**. |

### Unordered list

Use a **bulleted list** of items with a common theme that doesn't require a specific order.

For bullet list items consisting of complete sentences, use a period at the end of each sentence.

Use a period if there are more elements (such as a callout, code example, or image) between the introduction and the list.

## Tables

Use tables for items with three or more related data points.

Write an introductory sentence for the table and refer to the table's position using phrases like "the following table" or "the preceding table."

The introductory sentence must be a complete sentence, and it can end with:
- A colon if it immediately precedes the table.
- A period if there's more content (e.g., a callout) between the introduction and the table.

### When to use lists vs. tables

| Lists | Tables |
| ----- | ------ |
| Present a series of single items or steps. | Organize data with multiple attributes. |
| Outline product features (bulleted). | Compare installation requirements for different operating systems (columns). |
| Guide users through installation steps (numbered). | Show minimum and recommended specifications across products. |
