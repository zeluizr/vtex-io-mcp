# API authentication using user tokens

Whenever a user successfully logs in to a VTEX store, VTEX ID generates a JWT user token and sets it as the `VtexIdclientAutCookie` cookie.

- **Valid for:** 24 hours after creation
- **Usage:** Send as a header named `VtexIdclientAutCookie`

## Token scopes

| Scope | Who | Permissions |
|-------|-----|-------------|
| **Shopper** | Store customers | View active products, place orders, view orders from same profile. Cannot access VTEX Admin or change logistics settings. |
| **Admin** | Administrative users | Actions based on [License Manager roles](https://help.vtex.com/en/tutorial/roles--7HKK5Uau2H6wxE1rH5oRbc). May include Admin panel access and configuration editing. |

> User tokens are **not store-exclusive**. Admin users with access to multiple accounts can perform actions in all those stores with the same token.

## Generating user tokens

### Method 1 — VTEX IO CLI

1. Install the [VTEX IO CLI](https://developers.vtex.com/docs/guides/vtex-io-documentation-vtex-io-cli-install)
2. Log in to your account:
   ```bash
   vtex login {accountName}
   ```
3. Generate a user token:
   ```bash
   vtex local token
   ```
   The CLI prints the token to the terminal and copies it to the clipboard.

### Method 2 — VTEX ID API

Use the [Generate authentication token](https://developers.vtex.com/docs/api-reference/vtex-id-api#post-/api/vtexid/apptoken/login) endpoint (`POST /api/vtexid/apptoken/login`).

> **Note:** The token generated by this endpoint is tied to an **API key** (not a user profile). Its permissions match those defined for the `appKey`+`appToken` credential pair, not the logged-in user's permissions. It can still be used in the `VtexIdclientAutCookie` header.

## Usage in VTEX IO apps

In VTEX IO apps, user tokens are available via the IO context:

```typescript
import { IOContext } from '@vtex/api'

// Store user token (shopper scope)
ctx.storeUserAuthToken

// Admin user token (admin scope)
ctx.adminUserAuthToken
```

See [App authentication using auth tokens](https://developers.vtex.com/docs/guides/app-authentication-using-auth-tokens) for details.
