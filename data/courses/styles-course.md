# Making Your Store Unique

**Course ID:** styles-course
**Description:** Learn how to customize the appearance of your VTEX Store Framework storefront using CSS Handles, global styles, custom templates, and Markdown formatting.

## Overview

This course covers how to style and customize your VTEX IO store. Topics include: CSS Handles for component-level styling, `style.json` for global theme configuration, custom page templates with routes, rich text with Markdown, and search landing pages with custom queries.

---

## Step 00 — Introduction

VTEX Store Framework provides multiple ways to customize the appearance of your store:

1. **CSS Handles** — Target specific elements within blocks using CSS classes
2. **style.json** — Configure global typography, colors, and spacing (Tachyons-based)
3. **Custom Templates** — Create new page types beyond the default store pages
4. **Markdown in Rich Text** — Use Markdown syntax to format text content

---

## Step 01 — CSS Handles

### Concept

CSS Handles are CSS classes generated by VTEX blocks that allow you to style specific elements inside a block without overriding the entire block's styles.

Every block exposes a set of CSS Handles. To use them, create a CSS file at:
`styles/css/{app-vendor}.{app-name}.css`

For example, to style `vtex.store-components`:
`styles/css/vtex.store-components.css`

The `blockClass` prop lets you add a suffix to any block instance's CSS handles, enabling per-instance styling.

### Example CSS Handles for `info-card`:
- `.infoCardContainer`
- `.infoCardHeadline`
- `.infoCardSubhead`
- `.infoCardCallActionContainer`
- `.infoCardImage`

### Activity

1. Create `styles/css/vtex.store-components.css`
2. Style the info card headline and container
3. Use `blockClass` on the `info-card#vintage` block to scope styles

**Block configuration:**

```jsonc
// store/blocks/home.jsonc
{
  "store.home": {
    "blocks": ["info-card#vintage", "info-card#tech"]
  },
  "info-card#vintage": {
    "props": {
      "isFullModeStyle": false,
      "headline": "Vintage Collection",
      "callToActionMode": "button",
      "callToActionText": "Shop Now",
      "callToActionUrl": "/vintage",
      "imageUrl": "https://storecomponents.vteximg.com.br/arquivos/banner-principal.png",
      "blockClass": "vintage"
    }
  },
  "info-card#tech": {
    "props": {
      "isFullModeStyle": true,
      "headline": "Tech Collection",
      "callToActionMode": "button",
      "callToActionText": "Shop Now",
      "callToActionUrl": "/tech",
      "imageUrl": "https://storecomponents.vteximg.com.br/arquivos/banner-infocard2.png",
      "blockClass": "tech"
    }
  }
}
```

## Step 02 — Global Styles (style.json)

### Concept

The `styles/configs/style.json` file configures global visual settings for your store using the Tachyons-based design system. This file controls:

- Typography (font families, sizes, weights)
- Colors (semantic color tokens)
- Spacing scale

Changes in `style.json` affect the whole store consistently.

### Key sections:

```json
{
  "typography": {
    "font-family": "...",
    "heading-1": { "fontWeight": "...", "fontSize": "...", "fontFamily": "..." }
  },
  "semanticColors": {
    "background": { "base": "#color", "base--inverted": "#color" },
    "text": { "default": "#color", "on-base--inverted": "#color" },
    "action": { "primary": "#color", "secondary": "#color" }
  }
}
```

## Step 03 — Custom Templates

### Concept

VTEX IO allows you to create custom page templates beyond the standard store pages (home, product, search). A custom template requires:

1. A route definition in `store/routes.json`
2. A block file defining the template with a `store.custom#` prefixed template name

The template name must match the route key in `routes.json`.

### Activity

Create an "About Us" custom page:

1. Define the route:

```json
// store/routes.json
{
  "store.custom#about-us": {
    "path": "/about-us"
  }
}
```

2. Create the page template:

```jsonc
// store/blocks/about-us.jsonc
{
  "store.custom#about-us": {
    "blocks": ["flex-layout.row#about-us"]
  },
  "flex-layout.row#about-us": {
    "children": ["image#about-us", "flex-layout.col#text-about-us"]
  },
  "flex-layout.col#text-about-us": {
    "children": ["rich-text#about-title", "rich-text#about-content"],
    "props": {
      "preventVerticalStretch": true
    }
  },
  "rich-text#about-title": {
    "props": {
      "text": "# About Our Store"
    }
  },
  "rich-text#about-content": {
    "props": {
      "text": "We are a VTEX IO powered store."
    }
  },
  "image#about-us": {
    "props": {
      "src": "https://appliancetheme.vteximg.com.br/arquivos/cozinha-about-us.png",
      "maxHeight": "600px"
    }
  }
}
```

## Step 04 — Rich Text with Markdown

### Concept

The `rich-text` block's `text` prop accepts Markdown formatting. This enables headers, bold, italic, lists, and links.

Markdown in VTEX IO rich-text uses `\n` (escaped newline) to break lines within the JSON string.

Common Markdown syntax:
- `# H1`, `## H2`, `### H3` — headings
- `**bold**` — bold text
- `_italic_` or `*italic*` — italic text
- `- item` — unordered list item
- `[link text](url)` — hyperlink

### Activity

Update the About Us page rich text to use Markdown formatting:

1. Change `rich-text#about-content` so that "This is the VTEX Minimum Theme" becomes an `h3` heading
2. Put "VTEX Minimum Theme" in italic

```jsonc
// store/blocks/about-us.jsonc
{
  "rich-text#about-content": {
    "props": {
      "text": " ### This is the _VTEX Minimum Theme_ \n You can use it to test blocks usage and build your first store from scratch."
    }
  }
}
```

## Step 05 — Search Landing Page

### Concept

A search landing page is a custom template that displays search results for a specific, hard-coded query — useful for promotions and category campaigns.

`search-result-layout.customQuery` allows you to define the query directly in the block props via `querySchema`.

Key `querySchema` props:
- `orderByField` — sort order (e.g., `"OrderByReleaseDateDESC"`, `"OrderByPriceDESC"`)
- `hideUnavailableItems` — boolean, hide out-of-stock items
- `maxItemsPerPage` — integer, results per page
- `queryField` — the search term
- `mapField` — query type: `"ft"` for full-text, `"c"` for category, `"b"` for brand

### Activity

Create a `/landing` custom page that shows camera products:

1. Add route to `routes.json`:

```json
// store/routes.json
{
  "store.custom#about-us": {
    "path": "/about-us"
  },
  "store.custom#landing": {
    "path": "/landing"
  }
}
```

2. Create the landing page template:

```jsonc
// store/blocks/search-landing.jsonc
{
  "store.custom#landing": {
    "blocks": ["image#landingbanner", "search-result-layout.customQuery"]
  },
  "image#landingbanner": {
    "props": {
      "src": "https://storecomponents.vteximg.com.br/arquivos/box.png",
      "minWidth": "100%"
    }
  },
  "search-result-layout.customQuery": {
    "props": {
      "querySchema": {
        "orderByField": "OrderByReleaseDateDESC",
        "hideUnavailableItems": true,
        "maxItemsPerPage": 8,
        "queryField": "Blue Top Retro Camera",
        "mapField": "ft"
      }
    },
    "blocks": ["search-result-layout.desktop"]
  }
}
```

3. Ensure `search-result-layout.desktop` is defined (either in `search.jsonc` or directly in `search-landing.jsonc`).
